OpenAI モデル設定

Responses API に対応。GPT-5.6 ファミリーでレコード内容から回答を生成します。

推奨
gpt-5.6-sol
GPT-5.6 の最上位モデル。複雑な業務タスク向け。
gpt-5.6-terra / gpt-5.6-luna
品質・コストのバランス、または高スループット向け。

OpenAI設定

組織のセキュリティポリシーに沿って管理してください。
GPT-5.6 Sol は複雑な業務向け、Terra は品質・コストのバランス、Luna は高スループット向けです。
Responses API では reasoning.effort を指定します。GPT-5.6 は none から max まで対応し、デフォルトは medium です。既存モデルでは、選択できる値を従来どおり制限します。
AIの役割やトーンを指定します。未入力時は汎用アシスタントとして動作します。

kintoneフィールド設定

AIに渡す本文のフィールドコード。
AIの回答を保存するフィールドコード。
ボタンを配置するスペースフィールドのID。
